One word, one username, one reward. This entry sends the entrant's own
make.fun username — `mocsses` — and nothing else: no explanation, no links,
no pitch. A judge model reads two usernames at a time and picks the one that
feels funnier or more interesting.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes exactly `mocsses` (7 characters) to `out/entry.txt`.
